mnemos Sign in

Your notes, in plain files.

A folder of markdown - your Obsidian vault works - on the web and on Android. Nothing is locked in: every note stays an ordinary file next to the others.

Sign in ⬇ Android app (APK) Source code

This server holds one person's notes; there is no sign-up. The sign-in page has a read-only demo. Want your own? Host it yourself in three steps.

✍️ Markdown, live

Edit, Split or Preview. Task boxes you tick in the preview, find & replace, autosave that never overwrites someone else's edit.

🗂️ Four ways to browse

List, Box with previews, Tabs per folder, and Flow - one note at a time, swipe to the next.

🖼️ Images & tables

Paste or pick photos into a note (saved in attachments/); CSV opens as a real table.

🤝 Syncthing friendly

Conflict copies side by side, trash with restore, and one-tap cleanup that empties old trash.

📱 Android, online or offline

Use this server, or the folder Syncthing keeps on your phone. Widgets open the exact note.

🔒 Private

One user, bcrypt, signed cookies, IP bans for scanners and guessers, no tracking, no third-party requests.

Run your own

  1. Get it

    git clone https://gitlab.com/niharokz/mnemos.git && cd mnemos
cp .env.example .env

  2. Fill in .env

    openssl rand -hex 32     # MNEMOS_SECRET

    NOTE_PATH (your notes folder), MNEMOS_USER, MNEMOS_PASSWORD, PUID/PGID and TZ.

  3. Start it behind HTTPS

    docker compose run --rm mnemos check && docker compose up -d --build

    Point your proxy at mnemos:8080, sign in, then install the APK and choose My Mnemos server.

Everything else - Android build, releases, settings - is in the README.
