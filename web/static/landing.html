Your notes, in plain markdown, anywhere you are.

samanote is a small self-hosted web editor for a folder of markdown notes - for example the vault you already open in Obsidian. Pick a note, write, watch the preview update as you type, and it saves itself. Your notes stay ordinary .md files: no database, no lock-in, nothing extra written next to them.

✍️ Editor + live preview

Side by side on a desktop, one at a time on a phone. Markdown highlighting, find & replace, lists that continue on Enter, undo.

💾 Saves itself

Autosave a second after you stop typing, Ctrl S any time, and a status dot that tells you it is on disk.

🤝 Never loses an edit

Changed in Obsidian or by Syncthing while you typed? You choose: load theirs, keep yours, or save yours as a copy. Nothing is overwritten silently.

🔄 Picks up outside edits

Come back to the tab and a note that changed elsewhere reloads by itself - cursor and scroll kept - when you had nothing unsaved.

🗑️ Nothing is deleted

"Delete" moves a note to the vault's .trash folder, the one Obsidian uses. Restore it from there any time.

📄 Plain files

No database, no index, no extra files. Saves are atomic, line endings and file permissions are kept, unchanged notes are never rewritten.

🗂️ Folders & filter

A folder tree that remembers what is open, a filter box, new note or folder anywhere, rename and move that never overwrite.

📱 Any screen

Drawer and full-screen panes on a phone, resizable sidebar and split on a desktop. Add it to your home screen like an app.

🖼️ Real preview

Tables, task lists, footnotes, strikethrough, autolinks, properties, images from your vault, and links that open the other note.

🔒 Private by design

Single user, bcrypt password, signed cookies, login lockout, strict browser policies, no third-party requests and no tracking.

🪶 Tiny

One Go binary with the web app built in, in an empty Docker image. Runs as your own user with a read-only filesystem.

🌗 Light & dark

The nss teal theme follows your system, with a manual switch. Large tap targets, readable on any screen.

What it is not

samanote is a web editor for your files, not an Obsidian clone. On purpose, it has no:

  • wikilinks, backlinks, graph view, tags pane, embeds or callouts - use Obsidian for those, on the same files;
  • sync - pair it with Syncthing, git or whatever already moves your notes;
  • plugins, accounts for other people, or a database.

Install

You need a Linux box with Docker, your notes in a folder on it, and a reverse proxy that serves HTTPS (Caddy, Traefik, nginx, or a Cloudflare tunnel).

  1. Get the code

    git clone https://gitlab.com/niharokz/samanote.git
cd samanote
cp .env.example .env

  2. Set your login

    Build the image, then create a password hash and a secret key and paste both into .env (the hash in single quotes):

    docker compose build
read -rs PW && printf '%s' "$PW" | docker run --rm -i samanote:local hash-password
openssl rand -hex 32        # → SAMANOTE_SECRET

    Also set SAMANOTE_USER, NOTE_PATH (your notes folder), TZ, PUID/PGID (from id -u / id -g) and SAMANOTE_NETWORK (the Docker network your proxy is on).

  3. Check and start

    docker compose run --rm samanote check   # settings + any note or folder it could not write
docker compose up -d
docker logs samanote                     # "samanote … listening on :8080"

    If check lists folders owned by another user (often root, created by another container), give them back to you: sudo chown -R "$(id -u):$(id -g)" /path/to/notes.

  4. Put it behind HTTPS

    notes.example.com {
    reverse_proxy samanote:8080
}

    Open the site, sign in, then use your browser's Install / Add to Home Screen.

  5. Update later

    git pull && docker compose up -d --build

No Docker? With Go 1.23+: go build ./cmd/samanote, then SAMANOTE_NOTES=~/notes SAMANOTE_PASSWORD=… ./samanote serves http://localhost:8080.

Configure

.env - required

NOTE_PATH
host folder with your notes
SAMANOTE_USER
the single login
SAMANOTE_PASSWORD
a bcrypt hash from samanote hash-password (plain text works too)
SAMANOTE_SECRET
signs the session cookie, 32+ characters
PUID · PGID
the user that owns the notes
SAMANOTE_NETWORK
Docker network shared with your proxy

.env - optional

TZ
time zone, used in conflict-copy names
SAMANOTE_HIDDEN
extra folders to hide, comma separated (dot folders such as .obsidian always are)
SAMANOTE_AUTOSAVE_MS
autosave delay, default 1000
SAMANOTE_MAX_FILE_MB
bigger files open read-only, default 5

Security

  • The password can be stored as a bcrypt hash; user name and password are compared in constant time.
  • HMAC-signed, HttpOnly, Secure, SameSite cookie (__Host- prefixed). Changing the password or the secret signs every device out.
  • Five wrong passwords lock that IP out for 15 minutes; the real client IP is read safely behind Cloudflare and proxies.
  • Every change must be a same-origin JSON request with a custom header - cross-site forms and requests are refused.
  • Paths are locked inside your notes folder: no .., no symlinks pointing out, hidden folders stay hidden.
  • Strict Content-Security-Policy, HSTS, no framing, no third-party scripts, fonts or analytics. Files served raw are sandboxed.
  • Runs as your user in an empty, read-only container with no capabilities; it can only write to your notes folder.
  • Every change and sign-in is logged with time and client IP - never with passwords or note contents.
